## 2. Security & Role-Based Access Control (RBAC)

FAFLOW enforces 4 primary institutional role boundaries:

| Role | Permissions | Sample Allowed Operations |
| :--- | :--- | :--- |
| `system_admin` | Global Institutional Administration | Create/modify campus geofences, global backup/restore, tenant management |
| `admin` (HOD) | Departmental Administration | Manage department faculty, timetable approvals, departmental leave entries |
| `teacher` / `staff`| Self-Service & Attendance | Face enrollment, mobile attendance check-in/out, leave application |
| `principal` / `governance` | Read-Only Oversight | Institutional reporting, audit inspection, compliance tracking |

## 3. Server-Authoritative Geofence Validation

The backend guarantees campus perimeter enforcement in `AttendanceService._validate_server_geofence`:

```python
@staticmethod
def _validate_server_geofence(db: Session, lat: float, lon: float, accuracy: float) -> Tuple[bool, Optional[CampusGeofence]]:
    # 1. Enforce physical GPS accuracy ceiling
    if accuracy > 50.0:
        raise DomainException(f"GPS accuracy ({accuracy:.1f}m) exceeds allowable threshold (50.0m)", status_code=400)

    active_geofences = GeofenceService.list_geofences(db, is_active_only=True)
    if not active_geofences:
        return True, None

    # 2. Check all active institutional perimeters
    for g in active_geofences:
        if g.type == "circle":
            dist = AttendanceService._haversine_meters(lat, lon, g.center_latitude, g.center_longitude)
            if dist <= (g.radius_meters + g.tolerance_meters):
                return True, g
        elif g.type == "polygon":
            if GeofenceService._is_point_in_polygon(lat, lon, g.polygon_vertices):
                return True, g

    return False, None
```

## 4. Idempotency & Concurrency Safety

Every attendance submission requires an `idempotency_key` (UUIDv4) generated by the client. The database indexes `staff_attendance_records.idempotency_key` with a `UNIQUE` constraint. If a duplicate submission occurs during network retries, the existing record is returned without re-executing database mutations.
