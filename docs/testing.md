# FAFLOW Testing Strategy

> Generated by Phase 7 – End-to-End Verification & CI/CD Hardening  
> Branch: `optimize/full-audit`

---

## 1. Overview

FAFLOW is a monorepo with three independently-testable layers:

| Layer | Stack | Test runner |
|---|---|---|
| **Backend** | FastAPI + SQLAlchemy + PostgreSQL | `pytest` (SQLite in-memory) |
| **Frontend** | React 18 + TypeScript + Vite | `tsc` (type-check) + `vite build` |
| **Android** | Kotlin + Jetpack Compose + CameraX | `gradlew testDebugUnitTest` |

---

## 2. Backend Testing

### Test runner
```bash
cd backend
venv\Scripts\python.exe -m pytest tests/ -v --tb=short
```

### Configuration
- **`pytest.ini`** – `pythonpath=.`, `testpaths=tests`, `-v --tb=short`
- **`conftest.py`** – SQLite in-memory engine, `StaticPool`, per-test `create_all/drop_all`, dependency injection override for `get_db`

### Test suites (63 files, ~2 500+ test cases)

| Category | Key files |
|---|---|
| **Auth** | `test_auth_service.py`, `test_services_auth_service.py` |
| **Security** | `test_security.py`, `test_security_hardening.py`, `test_core_security.py` |
| **RBAC / Governance** | `test_governance.py`, `test_governance_control.py`, `test_governance_business_rules.py`, `test_policy.py`, `test_policy_enforcement.py` |
| **Attendance** | `test_attendance.py`, `test_student_attendance.py`, `test_student_attendance_gap_fixes.py`, `test_principal_student_attendance.py` |
| **Leave system** | `test_leave_service.py`, `test_leave_cancellation.py`, `test_leave_aware_substitution_fairness.py`, `test_staff_leaves_and_credits.py` |
| **Substitutions** | `test_substitution_service.py`, `test_substitution_dashboard.py`, `test_substitution_cutoff.py`, `test_substitution_suitability_audit.py`, `test_substitution_limit_warning.py` |
| **Campus** | `test_campus_duties.py`, `test_campus_structure.py`, `test_room_operations_and_duties.py` |
| **Infrastructure** | `test_api_contract_matrix.py`, `test_backend_optimizations.py`, `test_core_dependencies.py`, `test_schemas.py` |

### CI command (GitHub Actions)
```yaml
python -m pytest tests/ --tb=short -q \
  --junitxml=reports/pytest.xml \
  --cov=app --cov-report=xml:reports/coverage.xml \
  --cov-fail-under=70
```

## 3. Frontend Testing

### Type-check (mandatory)
```bash
cd frontend
npm run typecheck   # tsc --noEmit
```

### Production build (mandatory)
```bash
npm run build       # vite build – must exit 0
```

### What is checked
- Full TypeScript strict type inference across 579 modules
- React component imports, hook types, API response shapes
- Vite bundle chunk sizes (see output in CI artifacts)

> **No unit test framework is currently installed.** Recommended next step:
> add Vitest + React Testing Library for component-level tests.

## 4. Android Testing

### Unit tests
```bash
cd android
.\gradlew.bat testDebugUnitTest --no-daemon
```
Results: `app/build/reports/tests/testDebugUnitTest/`

### Debug APK build
```bash
.\gradlew.bat assembleDebug --no-daemon
```
APK: `app/build/outputs/apk/debug/`

### Current test suites

| File | Description |
|---|---|
| `FaceRecognitionProductionTest.kt` | Biometric liveness gate, settling window, spoofing protection |
| `AttendanceViewModelTest.kt` | State machine transitions (SEARCHING → SETTLING → CAPTURED) |

### Test infrastructure
- **JUnit 4** (`testImplementation(libs.junit)`)
- **Kotlinx Coroutines Test** (`kotlinx.coroutines.test`)
- **Headless support**: `testOptions { unitTests { isReturnDefaultValues = true } }` + null-bitmap guard in `AttendanceViewModel.updateDetections`

> **Recommended additions** (from testing-setup skill):
> - MockK for ViewModel/Repository unit tests
> - Robolectric for Compose UI tests without a device
> - Jacoco for code coverage reporting

## 5. Contract Parity Gate

Verifies that every API call in the Android and web clients maps to a real OpenAPI-spec path.

```bash
cd b:\FAFLOW_UNIFIED
backend\venv\Scripts\python.exe -X utf8 scripts\ci_contract_check.py \
  --openapi openapi.yaml \
  --android android\app\src\main\java\com\governence\faflow \
  --frontend frontend\src \
  --report reports\contract_parity.json
```

**Current result: PASS — 0 HIGH, 0 MEDIUM** (90 Android + 359 Frontend endpoints vs 653 OpenAPI paths)

    └── Job: gate            ✅ all must pass
