## 1. Executive Summary & Design Philosophy

Phase 2 establishes the **single source of truth** for all visual and interactive styling across the FAFLOW monorepo. Every color, dimension, radius, elevation shadow, and status badge across both the **Web Application (React 18 + Vite + Tailwind CSS)** and the **Mobile Client (Kotlin + Jetpack Compose + Material 3)** is strictly compiled from a single authoritative specification: `design/tokens/faflow_design_tokens.json`.

### Core Design Principles
1. **Light Institutional Elegance**: Clean, authoritative, slate-and-white surfaces with deep institutional navy accents. Zero muddy dark modes in standard workflow surfaces.
2. **Uncompromising Contrast (WCAG 2.2 AA)**: Every body and muted text element achieves $\ge 4.5:1$ contrast against its background. Every interactive control, input border, and checkbox achieves $\ge 3.0:1$ non-text contrast.
3. **Deterministic Single-Sourcing**: Manual token editing in frontend or Android source code is permanently prohibited. A bidirectional generator (`scripts/generate_design_tokens.py`) produces synchronized JavaScript exports, CSS variables, Tailwind themes, and Kotlin Compose data classes.
4. **Zero-Drift CI Enforced**: Automated CI jobs immediately fail any PR or commit where generated token files drift from the JSON source of truth, or where any token combination falls below WCAG 2.2 AA contrast standards.

## 3. Token Architecture

The design token structure follows the industry-standard three-layer hierarchy:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. PRIMITIVE TOKENS (Raw values)                            │
│    navy.600: #1B3A6B, slate.600: #475569, gold.700: #7A5806  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. SEMANTIC TOKENS (Contextual & Purpose Aliases)            │
│    brand.primary -> {navy.600}, border.control -> #828C99   │
│    status.warning.text -> {gold.700}, surface.card -> #FFF  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. COMPONENT BINDINGS (Platform & Widget Implementations)   │
│    React: .btn-primary, Input, StatusBadge, RoleBadge       │
│    Compose: PrimaryGradientButton, FaflowLightColorScheme   │
└─────────────────────────────────────────────────────────────┘
```

## 4. Single-Source Code Generation Pipeline

All token outputs are generated automatically from `design/tokens/faflow_design_tokens.json`.

```bash
# Generate all code bindings
python scripts/generate_design_tokens.py

# Verify CI compliance (fails on any drift)
python scripts/generate_design_tokens.py --check

# Verify WCAG 2.2 AA contrast ratios
python scripts/test_design_tokens_contrast.py
```
